TypeScript-native FHIRPath engine

Catch the mistake
before even testing.

Most FHIRPath engines catch a wrong path only when they run it — usually a silent empty result, at best an opt-in runtime error. This one reads the expression against the FHIR model first, so a typo or a type slip is a build-time failure, not a surprise in production. Type below and watch.
